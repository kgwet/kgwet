### Hi, I'm Kilem L. Gwet 👋

Mathematical Statistician | Research Statistician in Quantitative Psychometrics | Quantitative Management Consultant at **AgreeStat Analytics**, Maryland, USA

I develop statistical methods and open-source software for **inter-rater reliability** — chance-corrected agreement coefficients (AC1, AC2), intraclass correlation coefficients (ICC), and related psychometric tools used in research, healthcare, and quality-control settings.

---

**🔧 Featured projects**

- [**irrCAC**](https://github.com/kgwet/irrCAC) — R package for chance-corrected agreement coefficients (Gwet's AC1/AC2, Cohen's Kappa, Fleiss' Kappa, Krippendorff's Alpha, and more)
- [**irrICC**](https://github.com/kgwet/irrICC) — R package for intraclass correlation coefficients as measures of agreement
- [**pairedCAC**](https://github.com/kgwet/pairedCAC) — R package for testing statistical significance of differences between two agreement coefficients
- [**inter-rater-reliability-cac**](https://github.com/kgwet/inter-rater-reliability-cac) — R functions for computing inter-rater reliability coefficients for nominal, ordinal, and interval data
